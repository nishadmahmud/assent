# Assent Real Estate & Property Management Ltd.

Official website for **Assent Real Estate & Property Management Ltd.** - premier architectural developments, luxury residential towers, and institutional property management in Bangladesh.

## Tech Stack
- **Framework**: Next.js (App Router, Turbopack)
- **Styling**: Tailwind CSS v4
- **Language**: JavaScript (ESM, React 19)
- **Typography**: Playfair Display (Headings) & Inter (UI/Body)

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Key Features
- **Signature Flagship Showcase**: Assent Royal Heights (14-Story Luxury Tower facing 80' wide avenue).
- **Interactive Floor Plan Explorer**: Inspect 1st to 13th typical floors, Unit-A (4-Bed), Unit-B (4-Bed), rooftop terraces, and 21-bay parking blueprints in high resolution.
- **Full Property Lifecycle Services**: Development, Architectural Construction, Property & Facility Management, and Strategic Investment Consultancy.
- **Responsive & Accessible Design**: Seamless on desktop, tablet, and mobile.
